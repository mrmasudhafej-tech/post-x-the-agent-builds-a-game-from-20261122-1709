One prompt, one game, one short video. My AI agent was given a single prompt — "Build me a tiny browser game: catch the falling lanterns!" — while I watched, and built **Lantern Catch** (`game.html` in this repository): a canvas game where you move the basket, catch falling lanterns, build combos, climb levels, and keep three lives. The video shows the prompt, the agent working, and the finished game actually running, and ends with make.fun's referral end card carrying my referral code. The post itself is the entry: places go by the post's views plus 10 times its likes, reposts, quotes and replies.
